## 🌟 Features

- 🎨 **Premium glassmorphic interface** with frosted-glass panels, animated gradient orbs, and a dark luxury aesthetic.
- 📱 **Fully responsive layout** for mobile, tablet, and desktop screens.
- 👁️ **Password visibility toggles** for password and confirm-password fields.
- 📊 **Real-time password strength meter** with Weak, Fair, Good, Strong, and Secure states.
- ✅ **Live form validation** for names, email, password matching, and required terms acceptance.
- 🔔 **Toast notifications** for clear, immediate feedback.
- 🎉 **Success modal dialog** after a valid registration submission.
- 🚀 **Zero dependencies** — built with plain HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Run Locally

No package manager or build step is required.

```bash
git clone https://github.com/Sanjeet3065/Registration-Form.git
cd Registration-Form
python -m http.server 3000
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. You can also open `index.html` directly or use VS Code's Live Server extension.

## 🎯 Validation Details

1. **First and last name** must not be empty.
2. **Email address** is checked using a standard email pattern.
3. **Password** requires at least six characters and is evaluated for length, numbers, uppercase letters, and special characters.
4. **Confirm password** must match the original password.
5. **Terms and Conditions** must be accepted before submission.

> **Note:** This is a front-end demonstration. It does not connect to a backend or store user accounts.
